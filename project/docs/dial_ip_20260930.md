## 行为与代码索引

```text
本轮业务完成，允许关网
        ↓
停止 MQTT，排空旧连接回调
        ↓
设置 CFUN 0，核对读回
        ↓
旧 PDP 已断开？
  否 → 保持工作锁、延时检查 → 查询错误或超时则报错并重试
  是
        ↓
离线等待；关网过程中已收到的新报警请求仍保留
        ↓
按键或业务期限唤醒
        ↓
设置 CFUN 1，等待 SDK 自动重新联网
        ↓
运营商按 SIM/APN 策略分配 IP，地址可能与上次相同
        ↓
SDK 联网回调 → 零等待复制到队列 → 唤醒后台
        ↓
后台 UART0 打印实际 IPv4 / IPv6
        ↓
MQTT 连接、订阅 → 按既有规则推进注册、心跳及报警
        ↓
等待对应平台业务确认 → 返回业务及关网检查
```

前台按键、声光任务与后台网络任务并行。前台不执行 IP 打印或同步网络调用。普通 MQTT 重连仍是传输重连，不被伪装为重新拨号；本次不为每一条 MQTT 报文强制关网。

## 可能的问题与实板验收

1. 运营商重复分配相同 IP：属于允许结果；核对仍然出现真实断开及新建连通知，上报不得因地址相同受阻。
2. CFUN 0 后 PDP 查询仍激活或返回错误：采集完整错误和后续恢复日志，不以模式读回代替数据连接释放；软件保持工作锁及重试。
3. SDK 通知缺地址、突发通知超过队列容量或 UART 写入失败：观察 unavailable、dial-events dropped 及串口实际输出，不能以静态测试宣称每轮实板日志已齐全。
4. 连续至少三轮离线唤醒、拨号、IP 打印和心跳业务确认；包含正常按键报警、关网过程中按下、释放后重按。核对未确认报警仍保留，既有注册及心跳计时规则不变。
5. COM12 使用 115200 / 8N1，核对实际烧录总包 SHA-256 和同次上电完整日志。IP 日志只证明本机联网通知，不证明公网出口变化、平台注册成功或报警业务确认；同时检查是否反复复位以及恢复网络后的持续运行。
